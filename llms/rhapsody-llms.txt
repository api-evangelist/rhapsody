# Rhapsody

> Rhapsody Health Solutions is a US-headquartered (Boston, MA) healthcare interoperability company trusted by more than 1,900 healthcare organizations across 31 countries and named Best in KLAS for integration engines for 17 consecutive years. Its single platform spans integration engines (Rhapsody and Corepoint), an enterprise master patient index (Rhapsody Identity / EMPI), semantic terminology management, data governance (Guardian), and AI + Model Context Protocol support (Rhapsody Axon) — moving data across FHIR, HL7 v2, REST, CDA, X12/EDI, SQL, DICOM, AMQP, and MCP from one deployment.

Note for agents: Rhapsody is an enterprise, sales-led provider. There is no public self-serve API host or downloadable specification; the developer API reference lives behind an AWS Cognito SSO gate at docs.rhapsody.health. This file is generated by API Evangelist from public pages, not published by Rhapsody.

## Products
- [Rhapsody Integration Engine](https://rhapsody.health/solutions/rhapsody/): Flagship healthcare integration engine with a REST administration/management API; connects FHIR, HL7 v2, REST, CDA, X12/EDI, SQL, DICOM, AMQP, and MCP.
- [Corepoint Integration Engine](https://rhapsody.health/solutions/corepoint/): Top-ranked low-code integration engine; Administration REST API introduced in Corepoint 7.5.3 for auditing and configuration.
- [Rhapsody Identity (EMPI)](https://rhapsody.health/solutions/empi/): Enterprise master patient index for patient matching and identity resolution (NextGate lineage).
- [Rhapsody Semantic](https://rhapsody.health/solutions/terminology-management/): Terminology management and data standardization (LOINC/SNOMED, FHIR terminology).
- [Rhapsody Axon](https://rhapsody.health/solutions/rhapsody-axon/): AI integration agent with Model Context Protocol (MCP) support for agent-ready workflows.
